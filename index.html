アプリ概要

アプリ名 総研テックKB（ナレッジ管理システム）
種別 SPA (Single Page Application) / Domo カスタムアプリ（App Studio に配置）
技術スタック HTML / Vanilla JavaScript / Tailwind CSS v4 (CDN) / Domo AppDB (NoSQL) / JSZip 3.10.1（ZIP出力） / html2pdf.js 0.10.1（PDF出力） / Google Fonts（Open Sans・Noto Sans JP）
デザイン Domo App「DB営業予算管理」に準拠した配色（見出しグリーン #2F6E40、ニュートラルグレー基調）。ナビ: 記事一覧=インディゴ / ランキング=#33A65E / ドキュメント=#F5B679 / 新規投稿=グリーン
目的 社内のナレッジを一元管理・共有するプラットフォーム

データストア (Domo AppDB Collections)

コレクション名 用途
knowledgeItemsナレッジ記事本体
commentsコメント
notifications通知
knowledgeHistory更新履歴スナップショット
  • AppDB へのアクセスは manifest.json の proxyId（アプリインスタンス＝カード）経由で行う。存在しないIDの場合は 404 になる
  • 利用者には、カードの共有に加えて4つのコレクションへの READ / READ_CONTENT / CREATE_CONTENT / UPDATE_CONTENT / DELETE_CONTENT 権限が必要（不足時は 403）
  • 記事データの取得に失敗した場合はサンプルデータを作成せず、エラー内容をトーストで表示する（取得失敗を0件と誤認して本番データへ書き込まないため）

ナレッジ記事データ構造

{
  id: string (AppDB自動採番),
  title: string,
  category: string,
  content: Array<{
    type: 'text'|'image'|'file'|'code',
    value: string,      // text: 本文 / image・file: Data URL / code: コード本文
    name?: string,      // image・file: ファイル名
    mimeType?: string,  // file: MIMEタイプ
    language?: string   // code: 言語（json, bash, powershell 等）
  }>,  // 配列の順序＝本文中の表示位置
  tags: string[],
  customAttributes: Array<{key: string, value: string}>,
  authorId: string,
  authorName: string,
  status: 'published' | 'draft',
  createdAt: ISO8601,
  updatedAt: ISO8601,
  likeCount: number,
  likedBy: string[],
  commentCount: number,
  viewCount: number,
  permissions: Array<{
    targetType: 'everyone'|'user'|'group',
    targetId: string|null,
    targetName: string,
    level: 'read'|'read_edit'|'read_edit_delete'
  }>
}

機能一覧

1. 記事一覧 (page-list)

  • 公開済み記事を表形式で表示（タイトル / カテゴリ / 内容のまとめ（本文先頭100文字） / タグ一覧 / 更新日）。行クリックまたは Enter で詳細へ
  • 検索結果件数の表示
  • 検索結果の記事をJSONで一括ダウンロード（ZIP）: knowledge.json ＋ 記事ID別フォルダに添付ファイル（images/・files/）
  • タグ・カテゴリは名前から算出した色相で色分け（同じ名前は常に同じ色）
  • 全文検索（タイトル・本文・コードブロック・タグ・カスタム属性）
  • カテゴリフィルター
  • タグフィルター（複数選択）
  • 作成者フィルター
  • 並べ替え（新しい順・古い順・いいね数順）
  • カスタム属性フィルター（キー・値で絞り込み、バッジ表示）

2. 記事詳細 (page-detail)

  • タイトル・カテゴリ・タグ・作成者・作成日時・更新日時表示
  • カスタム属性表示
  • コンテンツ表示（テキスト・画像・ファイル・コードブロック混在、挿入した位置に表示）
  • 画像: インライン表示
  • ファイル: 本文中の挿入位置にファイル名付きダウンロードリンクを表示
  • コードブロック: 言語ラベル付きの等幅表示、「コピー」ボタンでクリップボードへコピー
  • 添付ファイル・画像一覧セクション（ファイル名 + ダウンロードボタン）
  • 添付画像一覧セクション（サムネイルグリッド、ホバーでDLボタン表示）
  • JSON / CSV ダウンロード（ZIP: 本体ファイル ＋ 記事IDフォルダに添付ファイル）
  • PDF出力（出力項目選択モーダル付き）
  • いいねボタン（トグル、通知送信）
  • コメント投稿・表示・削除
  • 編集ボタン（権限チェック: read_edit以上）
  • 削除ボタン（権限チェック: read_edit_delete のみ）
  • 履歴ボタン（更新履歴がある場合のみ有効）
  • 閲覧数カウントアップ

3. 新規投稿・編集フォーム (page-form)

  • タイトル入力
  • カテゴリ選択: 既存記事のカテゴリ一覧（重複除去・五十音順）から選択、または「+」ボタンで新規入力。新規入力欄に値があればそちらを優先
  • カテゴリ候補から除外するカテゴリ: 「経営」「総務」（app.js の HIDDEN_FORM_CATEGORIES で設定。既存記事のカテゴリ自体は変更しない）
  • コンテンツエディタ（contenteditable）
  • コードブロック挿入: 言語選択、Tabキーでインデント（スペース4つ）、高さ自動調整、削除ボタン
  • 画像・ファイル添付（ペースト・ドラッグ&ドロップ・選択）。カーソル位置に挿入
  • Web・Teams・Word 等からコピーした画像（data-type なしの img）も画像として保存
  • 本文が解析できない場合も、表示中のテキストがあれば本文として保存（フォールバック）
  • スクリーンショット貼り付け時: ユニーク名自動生成
  • タグ入力（Enter/追加ボタン、オートコンプリート）
  • カスタム属性入力（キー・値ペア、オートコンプリート）
  • 作成者（読み取り専用）
  • アクセス権限設定
  • 投稿ボタン・下書き保存ボタン・キャンセルボタン

4. ランキング (page-ranking)

  • 週間ランキング: スコア = いいね×3 + コメント×2 + 閲覧×1
  • 月間ランキング: スコア = いいね×5 + コメント×2 + 閲覧×1
  • 上位10件表示、1〜3位はメダルカラー

5. 通知機能

  • ベルアイコンで未読バッジ表示
  • いいね・コメント時に記事作成者へ通知送信
  • 通知パネル、クリックで該当記事へ遷移
  • すべて既読ボタン

6. 権限管理

  • 作成者: 常に read_edit_delete
  • everyone/user/group 単位で権限設定
  • 最高権限が適用される
  • Domo APIからユーザー・グループ一覧取得

7. 更新履歴

  • 編集保存時に旧バージョンのスナップショット保存
  • 履歴モーダルでバージョン一覧表示
  • 差分モーダルで変更前後を並列比較（コードブロックも比較対象）

8. エクスポート仕様

種類 出力内容
一括JSON（一覧）knowledge_export_YYYYMMDD_HHMMSS.zip ＝ knowledge.json（exportedAt, count, items）＋ <記事ID>/images/・<記事ID>/files/
JSON（詳細）記事1件のJSON（id 含む）。添付がある場合は ZIP に <記事ID>/images/・files/ を同梱
CSV（詳細）項目/値の2列（先頭行は id）。画像・添付ファイル・添付フォルダの行を追加。BOM付きUTF-8
PDF（詳細）A4縦・余白15mm。モーダルで「タイトル / 概要（ID・カテゴリ・タグ・作成者・作成日時・更新日時） / カスタム属性 / 詳細（本文・コード・画像・添付ファイル名）」を選択。選択内容はブラウザに保存
  • 本文テキスト中では画像を「[画像: ファイル名]」、添付を「[添付ファイル: ファイル名]」、コードを ```言語 のフェンスで表現
  • 同名ファイルは連番を付けて重複を回避し、ファイル名に使えない文字は置換

9. 初期化・エラー処理

  • 初期化はステップ単位（ユーザー情報 → Domoユーザー/グループ → 記事 → コメント → 通知 → 更新履歴 → …）で実行し、失敗時は「アプリの初期化中にエラーが発生しました（ステップ名: 詳細）」を表示
  • 記事が0件かつ取得成功時のみサンプルデータを作成

初回起動

  1. Domoのアプリページを開く
  2. 記事が1件もない場合は、サンプルデータ（3件の記事）が自動作成される
  3. ヘッダー右上に現在のログインユーザー名が表示される
  4. 「記事データを取得できませんでした」と表示される場合は、カードおよびAppDBコレクションへのアクセス権限を管理者に確認する

記事を読む

  1. 「記事一覧」ページの表で読みたい記事の行をクリック
  2. 詳細ページで内容を確認
  3. 本文中の添付ファイルリンク、または「添付ファイル・画像」セクションの「ダウンロード」ボタンでダウンロード
  4. 添付画像は「添付ファイル・画像」または「添付画像」セクションのDLボタンでダウンロード
  5. コードブロックは右上の「コピー」ボタンでクリップボードにコピー

記事を検索・絞り込む

  1. 検索バーにキーワードを入力（タイトル・本文・コードブロック・タグ・カスタム属性を横断検索）
  2. カテゴリ・タグ・作成者でフィルター
  3. 「カスタム属性で絞り込み」の「+ 条件を追加」でカスタム属性フィルターを追加
  4. 並べ替えで表示順を変更
  5. 絞り込み結果の件数は表の上に表示される

記事を投稿する

  1. 「新規投稿」ボタンをクリック
  2. タイトルを入力（必須）
  3. カテゴリを既存の一覧から選択、または「+」ボタンで新規カテゴリを入力（必須）
  4. 内容エディタにテキストを入力
  5. 画像・ファイルの添付方法（カーソル位置に挿入され、記事でも同じ位置に表示される）:
    • エディタ内でCtrl+Vでクリップボードから貼り付け
    • エディタ内にドラッグ&ドロップ
    • 「ファイルを選択」ボタンでファイル選択
  6. JSONやコマンド例は「コードブロックを挿入」で追加し、言語を選択して入力（Tabキーでインデント）
  7. タグを入力してEnterまたは「追加」ボタン（オートコンプリートあり）
  8. カスタム属性を「+ 属性を追加」で追加
  9. アクセス権限を設定（デフォルト: 全員が読取+編集）
  10. 「投稿する」または「下書き保存」をクリック

記事を編集する

  1. 記事詳細ページで「編集」ボタンをクリック（編集権限が必要）
  2. 内容を修正
  3. 「投稿する」をクリックして保存
  4. 保存時に自動的に更新履歴が作成される

記事を削除する

  1. 記事詳細ページで「削除」ボタンをクリック（削除権限が必要）
  2. 確認ダイアログで「はい」をクリック

いいね・コメント

  • 詳細ページのハートボタンでいいねをトグル
  • コメント欄にテキストを入力して「投稿」ボタン
  • 自分のコメントは「削除」ボタンで削除可能

更新履歴を確認する

  1. 記事詳細ページで「履歴」ボタンをクリック（履歴がある場合のみ有効）
  2. バージョン一覧から「変更を確認」をクリック
  3. 変更前後の差分を確認

ダウンロード・PDF出力

  • 一括ダウンロード: 記事一覧で絞り込み後「検索結果をJSONで一括ダウンロード（ZIP）」をクリック。knowledge.json と、記事IDごとのフォルダに添付ファイルが格納される
  • 記事単位: 詳細ページの「JSON」「CSV」をクリック。添付がある場合はZIPで、記事IDフォルダに添付ファイルが格納される
  • PDF: 詳細ページの「PDF」をクリックし、出力する項目（タイトル・概要・カスタム属性・詳細）を選んで「PDFを出力」。選択内容は次回も引き継がれる

ランキングを見る

  1. 「ランキング」タブをクリック
  2. 週間・月間タブで切り替え
  3. スコア計算式はタブ下に表示

権限設定について

権限レベル 閲覧 編集 削除
読取のみ ○ × ×
読取+編集 ○ ○ ×
読取+編集+削除 ○ ○ ○
  • 作成者は常に「読取+編集+削除」権限を持つ
  • 複数の権限設定がある場合、最も高い権限が適用される

注意事項

  • ファイル・画像はBase64形式でDomoのAppDBに保存されます
  • 大きなファイルはAppDBの容量制限に注意してください
  • スクリーンショット貼り付け時は自動的にユニークなファイル名（screenshot_xxx.png）が付与されます
  • Teams・SharePoint 等からコピーした画像は、元のURL参照として保存され、他のユーザーに表示されない場合があります。確実に保存するには、画像をファイルとして保存してからドラッグ&ドロップまたは貼り付けしてください
  • カテゴリ候補には「経営」「総務」は表示されません（既存記事のカテゴリは変更されません）
  • アプリの利用には、カードの共有に加えて AppDB コレクションへのアクセス権限が必要です（権限がない場合は HTTP 403 エラー）
