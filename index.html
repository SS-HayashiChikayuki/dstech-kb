アプリ概要

アプリ名 ナレッジ管理システム
種別 SPA (Single Page Application)
技術スタック HTML / Vanilla JavaScript / Tailwind CSS (CDN) / Domo AppDB (NoSQL)
目的 社内のナレッジを一元管理・共有するプラットフォーム

データストア (Domo AppDB Collections)

コレクション名 用途
knowledgeItemsナレッジ記事本体
commentsコメント
notifications通知
knowledgeHistory更新履歴スナップショット

ナレッジ記事データ構造

{
  id: string (AppDB自動採番),
  title: string,
  category: string,
  content: Array<{type: 'text'|'image'|'file', value: string, name?: string, mimeType?: string}>,
  tags: string[],
  customAttributes: Array<{key: string, value: string}>,
  authorId: string,
  authorName: string,
  status: 'published' | 'draft',
  createdAt: ISO8601,
  updatedAt: ISO8601,
  likeCount: number,
  likedBy: string[],
  commentCount: number,
  viewCount: number,
  permissions: Array<{
    targetType: 'everyone'|'user'|'group',
    targetId: string|null,
    targetName: string,
    level: 'read'|'read_edit'|'read_edit_delete'
  }>
}

機能一覧

1. 記事一覧 (page-list)

  • 公開済み記事をカード形式で表示
  • 全文検索（タイトル・本文・タグ・カスタム属性）
  • カテゴリフィルター
  • タグフィルター（複数選択）
  • 作成者フィルター
  • 並べ替え（新しい順・古い順・いいね数順）
  • カスタム属性フィルター（キー・値で絞り込み、バッジ表示）
  • 記事カードにサムネイル画像・タグ・いいね数・コメント数・権限バッジ表示

2. 記事詳細 (page-detail)

  • タイトル・カテゴリ・タグ・作成者・作成日時・更新日時表示
  • カスタム属性表示
  • コンテンツ表示（テキスト・画像・ファイル混在）
  • 画像: インライン表示 + ファイル名付きダウンロードリンク
  • ファイル: ファイル名 + ダウンロードボタン
  • 添付画像一覧セクション（サムネイルグリッド、ホバーでDLボタン表示）
  • いいねボタン（トグル、通知送信）
  • コメント投稿・表示・削除
  • 編集ボタン（権限チェック: read_edit以上）
  • 削除ボタン（権限チェック: read_edit_delete のみ）
  • 履歴ボタン（更新履歴がある場合のみ有効）
  • 閲覧数カウントアップ

3. 新規投稿・編集フォーム (page-form)

  • タイトル入力
  • カテゴリ選択（既存から選択 or 新規入力）
  • コンテンツエディタ（contenteditable）
  • 画像・ファイル添付（ペースト・ドラッグ&ドロップ・選択）
  • スクリーンショット貼り付け時: ユニーク名自動生成
  • タグ入力（Enter/追加ボタン、オートコンプリート）
  • カスタム属性入力（キー・値ペア、オートコンプリート）
  • 作成者（読み取り専用）
  • アクセス権限設定
  • 投稿ボタン・下書き保存ボタン・キャンセルボタン

4. ランキング (page-ranking)

  • 週間ランキング: スコア = いいね×3 + コメント×2 + 閲覧×1
  • 月間ランキング: スコア = いいね×5 + コメント×2 + 閲覧×1
  • 上位10件表示、1〜3位はメダルカラー

5. 通知機能

  • ベルアイコンで未読バッジ表示
  • いいね・コメント時に記事作成者へ通知送信
  • 通知パネル、クリックで該当記事へ遷移
  • すべて既読ボタン

6. 権限管理

  • 作成者: 常に read_edit_delete
  • everyone/user/group 単位で権限設定
  • 最高権限が適用される
  • Domo APIからユーザー・グループ一覧取得

7. 更新履歴

  • 編集保存時に旧バージョンのスナップショット保存
  • 履歴モーダルでバージョン一覧表示
  • 差分モーダルで変更前後を並列比較

目的

過去に発生したバグの先祖返り防止と、主要機能の動作確認

テストケース一覧

背景: setupEventListeners()内のadd-category-btnハンドラに不正コードが混入し、編集ボタンのイベントリスナーが登録されなくなるバグが発生した

手順:

  1. 記事一覧から任意の記事をクリック
  2. 詳細ページで「編集」ボタンをクリック
  3. 編集フォームが表示されることを確認

期待結果: 編集フォームページに遷移し、既存データが入力済みで表示される

NG条件: ボタンをクリックしても何も起きない、コンソールにエラーが出る

背景: else if (block.type === 'file') という不正コードが混入していた

手順:

  1. 新規投稿フォームを開く
  2. カテゴリ欄の「+」ボタンをクリック
  3. 新規カテゴリ入力欄が表示/非表示トグルすることを確認

期待結果: 入力欄がトグル表示され、表示時はフォーカスが当たる

NG条件: コンソールエラー、ボタンが反応しない

背景: fileタイプのブロックが詳細ページで表示されないバグがあった

手順:

  1. 新規投稿フォームを開く
  2. 任意のファイル（PDF等）をドラッグ&ドロップまたはファイル選択
  3. 投稿する
  4. 投稿した記事の詳細ページを開く
  5. ファイルブロックが表示されることを確認
  6. 「ダウンロード」ボタンをクリック

期待結果: ファイル名とダウンロードボタンが表示され、クリックでダウンロードが開始される

NG条件: ファイルが表示されない、ダウンロードできない

背景: 画像にダウンロードリンクが追加された

手順:

  1. 新規投稿フォームを開く
  2. 画像ファイルをエディタに追加
  3. 投稿する
  4. 詳細ページで画像が表示されることを確認
  5. 画像下のダウンロードリンクをクリック

期待結果: 画像がインライン表示され、ファイル名付きダウンロードリンクが表示される

NG条件: 画像が表示されない、ダウンロードリンクがない

背景: クリップボードからの画像貼り付け時にユニークなファイル名が生成されるよう修正された

手順:

  1. 新規投稿フォームを開く
  2. 画面をスクリーンショット（PrintScreen等）
  3. エディタ内でCtrl+Vでペースト
  4. 投稿する
  5. 詳細ページで画像のダウンロードリンクのファイル名を確認

期待結果: screenshot_<数字>_<英数字>.png 形式のファイル名が表示される

NG条件: ファイル名が image.png のまま、またはファイル名が空

背景: textBuffer変数の宣言漏れによりエラーが発生するバグがあった

手順:

  1. 新規投稿フォームでタイトル・カテゴリ・内容を入力
  2. 「投稿する」ボタンをクリック
  3. 正常に保存されることを確認

期待結果: 「ナレッジを投稿しました」トーストが表示され、一覧ページに遷移する

NG条件: コンソールに「textBuffer is not defined」エラー、保存されない

手順:

  1. 画像を含む記事の詳細ページを開く
  2. 「添付画像」セクションのサムネイルにマウスオーバー
  3. 「DL」ボタンが表示されることを確認
  4. DLボタンをクリック

期待結果: ホバー時にDLボタンが表示され、クリックでダウンロードが開始される

NG条件: DLボタンが表示されない

手順:

  1. 自分が作成した記事の詳細ページを開く
  2. 編集・削除ボタンが有効であることを確認

期待結果: 作成者は編集・削除ボタンが両方有効

NG条件: 作成者なのにボタンが無効（disabled）

手順:

  1. 既存記事を編集して保存
  2. 詳細ページで「履歴」ボタンをクリック
  3. 履歴モーダルにバージョンが表示されることを確認
  4. 「変更を確認」をクリックして差分モーダルを確認

期待結果: 変更前後の内容が並列表示される

NG条件: 履歴が表示されない、差分が表示されない

手順:

  1. 他ユーザーの記事にいいね・コメントをする
  2. ベルアイコンの未読バッジを確認
  3. 通知パネルを開いて通知内容を確認

期待結果: 未読バッジが表示され、通知内容が正しく表示される

初回起動

  1. Domoのアプリページを開く
  2. 初回はサンプルデータ（3件の記事）が自動作成される
  3. ヘッダー右上に現在のログインユーザー名が表示される

記事を読む

  1. 「記事一覧」ページで読みたい記事カードをクリック
  2. 詳細ページで内容を確認
  3. 添付ファイルは「ダウンロード」ボタンでダウンロード
  4. 添付画像は画像下のリンクまたは「添付画像」セクションのDLボタンでダウンロード

記事を検索・絞り込む

  1. 検索バーにキーワードを入力（タイトル・本文・タグ・カスタム属性を横断検索）
  2. カテゴリ・タグ・作成者でフィルター
  3. 「カスタム属性で絞り込み」の「+ 条件を追加」でカスタム属性フィルターを追加
  4. 並べ替えで表示順を変更

記事を投稿する

  1. 「新規投稿」ボタンをクリック
  2. タイトルを入力（必須）
  3. カテゴリを選択、または「+」ボタンで新規カテゴリを入力（必須）
  4. 内容エディタにテキストを入力
  5. 画像・ファイルの添付方法:
    • エディタ内でCtrl+Vでクリップボードから貼り付け
    • エディタ内にドラッグ&ドロップ
    • 「ファイルを選択」ボタンでファイル選択
  6. タグを入力してEnterまたは「追加」ボタン（オートコンプリートあり）
  7. カスタム属性を「+ 属性を追加」で追加
  8. アクセス権限を設定（デフォルト: 全員が読取+編集）
  9. 「投稿する」または「下書き保存」をクリック

記事を編集する

  1. 記事詳細ページで「編集」ボタンをクリック（編集権限が必要）
  2. 内容を修正
  3. 「投稿する」をクリックして保存
  4. 保存時に自動的に更新履歴が作成される

記事を削除する

  1. 記事詳細ページで「削除」ボタンをクリック（削除権限が必要）
  2. 確認ダイアログで「はい」をクリック

いいね・コメント

  • 詳細ページのハートボタンでいいねをトグル
  • コメント欄にテキストを入力して「投稿」ボタン
  • 自分のコメントは「削除」ボタンで削除可能

更新履歴を確認する

  1. 記事詳細ページで「履歴」ボタンをクリック（履歴がある場合のみ有効）
  2. バージョン一覧から「変更を確認」をクリック
  3. 変更前後の差分を確認

ランキングを見る

  1. 「ランキング」タブをクリック
  2. 週間・月間タブで切り替え
  3. スコア計算式はタブ下に表示

権限設定について

権限レベル 閲覧 編集 削除
読取のみ ○ × ×
読取+編集 ○ ○ ×
読取+編集+削除 ○ ○ ○
  • 作成者は常に「読取+編集+削除」権限を持つ
  • 複数の権限設定がある場合、最も高い権限が適用される

注意事項

  • ファイル・画像はBase64形式でDomoのAppDBに保存されます
  • 大きなファイルはAppDBの容量制限に注意してください
  • スクリーンショット貼り付け時は自動的にユニークなファイル名（screenshot_xxx.png）が付与されます
